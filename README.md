# Employee Management System (Java)

A simple Java console application that demonstrates the use of classes, constructors, objects, and user input using the `Scanner` class.

## Features

- Accepts details of two employees.
- Stores employee information using objects.
- Displays employee details.
- Demonstrates object-oriented programming concepts in Java.

## Technologies Used

- Java
- Scanner Class
- Object-Oriented Programming (OOP)

## Program Details

The program accepts:
- Employee ID
- Employee Name
- Employee Salary

It then creates two `Employee` objects and displays their details.

## How to Run

1. Clone the repository.
2. Open the project in your Java IDE (Eclipse, IntelliJ IDEA, or VS Code).
3. Compile the program.
4. Run `Employee.java`.
5. Enter the employee details when prompted.
